프로젝트 소개

React2Shell (CVE-2025-55182)은 Next.js 15.0.0 버전의 React Server Component(RSC) 아키텍처에서 발견된 강력한 역직렬화 기반의 원격 코드 실행(RCE) 취약점입니다. 최신 React 생태계의 내부 동작 원리를 심층적으로 분석하기 위해 진행되었습니다.

기획 의도

  • 최신 프론트엔드 프레임워크(Next.js) 내부의 RSC 역직렬화(Deserialization) 메커니즘 이해
  • 알려지지 않은 Server Action 내부 동작 과정에서의 취약성 탐구 및 증명
  • 실제 클라우드 및 SaaS 환경에서 적용할 수 있는 안전한 대응 가이드라인 도출

수행 역할

  • Vulnerability Analysis: Next.js 서버의 Action State 파싱 로직 및 `__esModule` 속성을 활용한 객체 주입 가능성 분석
  • PoC Development: Node.js `child_process.exec`를 호출할 수 있는 `$$ACTION_ID` 연계 페이로드 작성
  • Verification: RCE 및 서버 장애 유발(DoS), 정보 유출(Info Leak) 시나리오 검증 시스템 구축 (Docker)

주요 성과 및 인사이트

  • 서버 권한 탈취가 가능한 RCE 공격 성공 및 원리 완벽 재현
  • RSC와 Server Actions 내부 동작 원리에 대한 깊은 기술적 이해도 및 보안 진단 역량 입증
  • 단순한 취약점 증명을 넘어 Next.js 인프라(Vercel 등) 환경을 고려한 아키텍처 레벨의 방어 로직 연구

프로젝트 소개

Spring4Shell (CVE-2022-22965)은 Spring Framework Core에서 발생한 심각한 원격 코드 실행(RCE) 취약점입니다. 해당 취약점의 동작 원리를 심층 분석하고, 실제 공격 시나리오(WebShell Upload)를 재현하여 방어 전략을 수립하기 위해 연구를 진행했습니다.

기획 의도

  • Spring Core의 DataBinder 메커니즘과 객체 바인딩 오류 원리 심도 있는 이해
  • JDK 9+의 Module 시스템 특성을 활용한 우회 공격 기법 분석
  • 실제 공격 재현을 통한 엔터프라이즈 환경에서의 파급력 검증 및 보안 대응책 마련

수행 역할

  • Vulnerability Analysis: CVE-2022-22965 원인이 되는 `CachedIntrospectionResults` 및 `class.module.classLoader` 접근 제어 취약성 분석
  • PoC Development: Tomcat의 `AccessLogValve` 속성 조작을 악용한 WebShell 생성 공격 일련의 페이로드 작성
  • Verification: Burp Suite를 활용하여 WAS 장악 시나리오 검증 및 WAF 우회 가능성 테스트 수행

주요 성과 및 인사이트

  • Spring Boot 2.6.5 + Java 11 환경에서 RCE 공격 성공 및 WebShell 악용 시나리오 재현
  • 프레임워크의 편리한 기능(Data Binding)이 강력한 취약점(Chain of Trust Broken)으로 변모할 수 있음을 실증
  • 다양한 WAF 벤더(AWS, Akamai)의 방어 정책 실효성을 식별하고, 자체적인 Suricata/Snort 기반 탐지 규칙 제안 역량 확보

프로젝트 소개

Log4Shell (CVE-2021-44228)은 Java 기반 로깅 유틸리티인 Log4j에서 발견된, IT 역사상 가장 파급력이 컸던 취약점 중 하나입니다. 널리 쓰이는 라이브러리인 만큼 해당 JNDI Injection의 원리를 완벽하게 분해하고 공격 방어 프로세스를 정립하기 위해 연구되었습니다.

기획 의도

  • 로깅 라이브러리의 JNDI Lookup 기능이 어떠한 방식으로 원격 코드 실행을 유발하는지 분석
  • LDAP 및 RMI 프로토콜을 이용한 원격 객체 로딩 및 역직렬화 공격 플로우 완벽 이해
  • 난독화 및 우회 기법(Obfuscation)에 대응하는 실무적 차원의 탐지 로직 도출

수행 역할

  • Vulnerability Analysis: Log4j `PatternLayout` 및 `MessagePatternConverter`에서의 문자열 치환 로직 분석
  • PoC Development: 악성 LDAP 서버 구축 및 HTTP 헤더(`X-Api-Version`)를 통한 악성 JNDI 페이로드 전송 스크립트 작성
  • Verification: 원격 서버 컴파일 코드가 타겟 컨테이너에 다운로드 및 실행(`RCE`)되는 전 단계 모니터링 및 실증

주요 성과 및 인사이트

  • 취약한 Log4j 환경 구축 및 강력한 JNDI 임의 코드 실행 공격 모듈 구축 완료
  • 공격자의 다양한 난독화 페이로드(`${lower:j}ndi...`) 원리 분석을 통해, 단편적인 문자열 차단을 넘어선 심층 방어 아키텍처의 중요성 확인
  • 오픈소스 라이브러리의 Supply Chain 위험성과 이를 조기에 식별 및 패치하는 ISMS 기반 운영의 필요성 시사

프로젝트 소개

Vuln-Camp는 프론트엔드와 백엔드를 연동한 실제 이커머스 아키텍처(Spring Boot + Next.js)를 기반으로 직접 기획/개발한 '취약점이 내재된 웹 어플리케이션(Vulnerable-by-Design)'입니다. 단순한 튜토리얼을 넘어 웹 비즈니스 로직 곳곳에 숨겨진 14가지 취약점을 분석하고 스스로 보안 코딩(Secure Coding) 가이드를 도출하기 위해 제작했습니다.

기획 의도

  • 하이브리드 시스템(SSR & CSR 혼합) 환경에서의 취약점 발생 메커니즘 및 연계 공격 원리 탐구
  • OWASP Top 10을 포함한 주요 취약점 14종을 결제 금액 조작, 인증 우회 등 실제 서비스와 유사한 시나리오로 구현
  • 설계자 겸 방어자 관점에서 취약점 패치 및 근본적인 방어 로직(Secure Coding)을 고도화하는 경험 축적

수행 역할

  • Injection: Blind SQL Injection, Stored XSS 등 사용자 입력값 기반의 주입 공격 벡터를 게시판, 로그인, Q&A 기능에 직접 설계 및 구현
  • 권한 우회 / 인증 결함: 객체 참조 조작(IDOR), CSRF를 통한 타 사용자 비밀번호 강제 변경, 인증 없이 관리자 페이지 접근 등 인가 누락 시나리오 구현
  • 서버 측 취약점: SSRF를 이용한 내부 시스템 접근, Path Traversal 기반의 소스코드 유출, 디렉토리 리스팅을 통한 민감 파일 노출 등 서버 측 공격 체인 구성
  • 클라이언트 로직 조작: 브라우저 단 검증 로직을 우회하여 쿠폰 강제 발급 및 결제 금액 파라미터를 조작하는 Parameter Tampering 공격 로직 설계
  • 취약점 분석 리포트: 14건의 취약점에 대해 공격 원리, Payload, 그리고 Secure Coding 패치 방법까지 구조화한 상세 리포트 작성

주요 성과 및 인사이트

  • 백엔드(Spring Boot) API 및 취약점 로직을 직접 설계·구현하여 웹 서비스의 보안 아키텍처를 강력하게 구성하였으며, 프론트엔드(Next.js)는 AI 도구를 활용해 빠르게 스케폴딩하여 프로젝트 효율을 극대화
  • 14종의 보안 취약점을 직접 코드 레벨에서 구현하고, 각 취약점에 대해 Secure Coding 대응 방안을 스스로 도출하며 공격자와 방어자 양쪽의 시각을 동시에 체험
  • 프론트엔드 ↔ 백엔드 간 신뢰 경계(Trust Boundary)의 설계적 한계를 실증하고, 실무 투입 시 개발팀에 즉각적이고 구체적인 보안 가이드라인을 제시할 수 있는 역량 확보
